# Windows 파일 시스템 검증

native directory handle은 delete 공유를 차단하여 활성 replica의 루트 및 journal 이름 변경을 방지한다. 종료 후 잠금이 해제됨을 검증한다. 디렉터리 handle은 읽기·쓰기 공유를 허용하여 hard-link capability probe와 함께 동작하며, payload 파일의 write 공유는 허용하지 않는다. watcher는 native reparse 속성을 검사하여 실제 심볼릭 링크 루트와 하위 항목을 제외한다.

동기화 한 회차의 사진 identity 예산 16개는 업로드 승인 후 재조회에도 유지된다. 재시작한 다음 회차에 나머지 항목이 내려받아지는 기존 회귀 시나리오와 중복 없는 16개 경로를 검증한다. 다수의 실제 파일 전송 시나리오를 포함한 Qt 테스트 실행 파일의 총 CTest 제한은 600초이다. 개별 작업·전송 응답 제한은 유지한다.

MetadataFirst의 사진 identity 예산은 실제 commit한 파일을 기준으로 start 한 번당 16개이다. 저널 재조회는 선택 목록만 갱신하며 완료 예산을 초기화하지 않는다.

전체 manifest 순서 회귀 테스트의 Windows 대기 예산은 외장 NTFS의 파일별 metadata I/O를 반영하여 60초이다. 실제 manifest가 모두 교환되기 전 파일 바이트가 전송되지 않는다는 assertion과 transfer window 검증은 유지한다.
